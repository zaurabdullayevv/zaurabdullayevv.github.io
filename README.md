# One-time GitHub Pages upload

This is the prebuilt portfolio. No Node.js installation or build is required.

1. Keep your existing browser and ChatGPT GitHub connections unchanged. Open a private/incognito browser window and sign into GitHub as zaurabdullayevv.
2. Create a PUBLIC repository named zaurabdullayevv.github.io. Do not select a template or add another website.
3. Extract this ZIP. Use GitHub's "uploading an existing file" link (or Add file → Upload files). Drag the extracted CONTENTS into the repository, including the assets folder. Keep index.html at the repository root. Do not upload this ZIP or a containing folder. Commit to main.
4. Open Settings → Pages. Under Build and deployment, select Deploy from a branch, main, and / (root), then Save.
5. Wait for publication. Settings → Pages will show the confirmed website URL and Visit site action. The expected address for this repository is https://zaurabdullayevv.github.io/.

If hidden files are not shown by your file manager, enable hidden files to upload .nojekyll as well. The visible assets directory and index.html must be uploaded together.

This ZIP is a deployment package, not the editable React source repository. Keep the previously supplied complete portfolio ZIP for future edits. No repository has been created and no GitHub deployment has been performed by preparing this package.
